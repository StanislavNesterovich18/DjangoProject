# Проект "Django basics"

## Описание:

Реализованы шаблоны страниц: домашняя и контакты.
Реализована форма обратной связи.
POST запрос возвращает приветствие и сообщение об успешном получении сообщения.

## Установка:

1. Клонируйте репозиторий проекта

2. Установите зависимости внутри каталога проекта для создания виртуального окружения и установки зависимостей
